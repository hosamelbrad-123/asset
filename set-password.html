إنشاء ملف كلمة السر (access.json)

اكتب كلمة السر الجديدة (12 حرفًا أو أكثر). الصفحة تعمل على جهازك فقط ولا ترسل كلمة السر لأي مكان.

  1. انسخ المحتوى أعلاه.
  2. على GitHub افتح الملف access.json (أو أنشئه لأول مرة في نفس مجلد index.html) واضغط Edit.
  3. الصق المحتوى مكان القديم واضغط Commit changes.
  4. خلال دقائق، كل موبايل يفتح التطبيق وفيه إنترنت سيطلب كلمة السر الجديدة.
